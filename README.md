# 🇮🇳 Aadhaar Insights Dashboard (2026 Hackathon Edition)

A premium, interactive geospatial dashboard for visualizing Aadhaar enrolment and update trends across India. Built with **Streamlit** and **Plotly**.

## 🚀 Features
- **Interactive India Map**: dynamic zooming and panning.
- **Drill-down Capability**: Select a state to auto-zoom and view specific data.
- **Metric Toggles**: Switch between Enrolment, Updates, and Rejections.
- **Anomaly Detection**: Highlight regions with high rejection rates.
- **Premium UI**: Clean, modern aesthetics with responsive design.

## 🛠️ Tech Stack
- **Python 3.8+**
- **Streamlit**: Web framework
- **Plotly Express**: Interactive maps
- **Pandas**: Data manipulation

## 📦 Installation

1. **Clone/Download** the repository.
2. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Generate Data** (if not present):
   ```bash
   python utils/data_generator.py
   ```

## ▶️ How to Run
Run the Streamlit app:
```bash
streamlit run app.py
```
 The dashboard will open in your default browser (usually http://localhost:8501).

## 📊 Data Source
- **Metrics**: Synthetic data generated by `utils/data_generator.py`.
- **Geospatial**: Public India States GeoJSON (fetched dynamically).

## 🎨 Customization
- **Styles**: Edit `styles/main.css` for UI tweaks.
- **Logic**: Modify `app.py` for layout changes or `utils/map_renderer.py` for map styling.
